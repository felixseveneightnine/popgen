# Templates

Paste the game's base robot template files here:

- `robot_standard.pop`
- `robot_giant.pop`

These define the standard `TFBot` templates (`T_TFBot_Scout`, `T_TFBot_Giant_Heavy`,
etc.) that missions `#base` and reference by `Template` name. Once these are here,
the robot picker in the wave editor sidebar will be wired up to read from them.
